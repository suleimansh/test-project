# Project Description

**test-project** is a minimal static website: a single HTML page that greets
visitors with "Hello, and welcome." on a dark, centered layout.

It has no build step and no dependencies — just `index.html` with inline styles
and a pair of favicons. The site is published automatically to GitHub Pages on
every push to `main`, and is live at
**https://suleimansh.github.io/test-project/**.

See [README.md](README.md) for how to run it locally and how deployment works.
