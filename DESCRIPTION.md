# Description

**Hello** is a minimal static web page. It shows a single centered greeting —
"Hello, and welcome." — in light text on a dark slate background (`#0f172a`),
with a matching "H" favicon. There is no build step, no JavaScript, and no
runtime dependencies: the whole page is one HTML file with inline styles.

## What it is for

A small, self-contained site for exercising the project's workflow end to end:
editing, reviewing, and publishing through GitHub Pages.

## Where it lives

- **Live site:** https://suleimansh.github.io/test-project/
- **Source:** `index.html`, `favicon.svg`, `favicon.ico`
- **Deploy:** `.github/workflows/deploy.yml` publishes on every push to `main`

See `README.md` for how to run it locally and how deployment works.
