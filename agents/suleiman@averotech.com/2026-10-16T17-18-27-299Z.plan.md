# Add a contact page and a footer link to it

The site is one static page, index.html, in the repository root, with no build step
and no JavaScript. All of its CSS is in one inline <style> block in the <head>:
`html, body` use flexbox (display: flex; align-items: center; justify-content: center;
height: 100%; margin: 0) to center the content on a dark slate background (#0f172a),
with the font stack -apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif.
The h1 is #f8fafc, 3rem, weight 600. The <head> holds <!DOCTYPE html>, <html lang="en">,
<meta charset="UTF-8">, the viewport meta, a <title>, and two relative favicon links
(favicon.ico with sizes="32x32", favicon.svg with type="image/svg+xml").
Style: HTML elements are not indented (all at column 0); only the CSS inside <style>
is indented, 2 spaces per level. Double-quoted attributes, no self-closing slash on
void elements, LF line endings with a final newline.
The site is deployed to GitHub Pages under the /test-project/ subpath, so every link
and asset path must be relative (contact.html, not /contact.html).
.github/workflows/deploy.yml publishes only the files named on its "cp ... _site/" line.
Do not push, do not open a pull request, and do not touch files outside your task's list.

Check: grep -q 'href="contact.html"' index.html && grep -q 'href="index.html"' contact.html && grep -q 'contact.html' .github/workflows/deploy.yml

## Create the contact page

Level: simple
Files: contact.html, .github/workflows/deploy.yml
Check: grep -q '<h1>Contact</h1>' contact.html && grep -q 'href="index.html"' contact.html && grep -q 'issues' contact.html && grep -q 'cp index.html contact.html' .github/workflows/deploy.yml
Uncertainty: 0

Create contact.html in the repository root, matching index.html's style exactly: copy
its <head> (same doctype, lang, charset, viewport, the two favicon links with their
comment, and the same inline <style> block), with the title "Contact". The body holds,
unindented: <h1>Contact</h1>, one short paragraph saying questions go to the GitHub
repository's issues, and a link back to the home page with href="index.html".
Because the body is a flex row, add to the <style> block `flex-direction: column;` on
`html, body` so the heading, paragraph and link stack vertically, plus a `p, a` rule
(or similar) giving them color #f8fafc so they read on the dark background; keep the
2-space CSS indentation.
In .github/workflows/deploy.yml, change the staging line
`cp index.html favicon.ico favicon.svg _site/` to
`cp index.html contact.html favicon.ico favicon.svg _site/` so the page is published.
Commit your work.
