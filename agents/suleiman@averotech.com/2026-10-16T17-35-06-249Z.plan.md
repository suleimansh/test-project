# Add an About page, a Files page, and a nav linking them from index.html

The repo is a tiny static site with no build step and no dependencies. The only
page today is `index.html` at the repo root: markup plus one inline `<style>`
block, dark background `#0f172a`, light text `#f8fafc`, system font stack
(`-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif`), content
centred with flexbox, `<html lang="en">`, the two favicon `<link>` tags.
New pages must match that style: copy its `<head>` (charset, viewport, the two
favicon links and their comment), its colours, font and centring, and keep all
CSS inline in a `<style>` block. No external CSS, JS or frameworks.

Every link must be relative (`about.html`, not `/about.html`): the site is served
from the `/test-project/` subpath on GitHub Pages, so a root-absolute href 404s.

Do not touch `favicon.*`, `.the-framework/`, `.agents/`, `.claude/`, `.openagent/`
or `node_modules/`. Touch only the files your task lists.

Check: test -f about.html && test -f files.html && grep -q 'href="about.html"' index.html && grep -q 'href="files.html"' index.html && grep -q 'about.html' .github/workflows/deploy.yml && grep -q 'files.html' .github/workflows/deploy.yml && ! grep -n 'href="/' index.html about.html files.html

the home page: `<a href="index.html">Home</a>`, styled in the page's light colour.
