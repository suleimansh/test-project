# Add an About page, a Files page, and a nav to the static site

The repo is a small static site served by GitHub Pages: `index.html` is the whole
site today, with inline styles and no build step, no dependencies, no JavaScript.
Read `index.html` and `README.md` before you start.

Style every new page like `index.html`: the same `<head>` (charset, viewport, the
two favicon `<link>`s with relative hrefs `favicon.ico` and `favicon.svg`), one
inline `<style>` block, background `#0f172a`, text colour `#f8fafc`, the same
`font-family` stack, content centred with flexbox. Every link is relative
(`about.html`, never `/about.html`): the site is served from the `/test-project/`
subpath, so a root-absolute href 404s. Write plain, short copy. Do not touch any
file outside your task's `Files:` line, and do not push or open a pull request.

Check: for f in index.html about.html files.html; do test -f "$f" || exit 1; done && grep -q 'href="about.html"' index.html && grep -q 'href="files.html"' index.html && grep -q 'about.html' .github/workflows/deploy.yml && grep -q 'files.html' .github/workflows/deploy.yml && ! grep -q 'href="/' index.html about.html files.html

## Write the About page (about.html)

Level: simple
Files: about.html
Check: grep -q '<p>' about.html && grep -q 'No build step' about.html && grep -q '#0f172a' about.html && grep -q 'href="index.html"' about.html
Uncertainty: 0

Create `about.html`: a page titled "About" with one short paragraph saying what this
repo is, taken from the opening paragraph of `README.md` (a single static page, no
build step, no dependencies, one centred greeting on a dark background). Keep the
README's phrase "No build step" verbatim. Under the paragraph, add a relative link
back to the home page: `<a href="index.html">Home</a>`. Style links so they are
readable on the dark background (e.g. colour `#93c5fd`).

## Write the Files page (files.html)

Level: simple
Files: files.html
Check: grep -q 'README.md' files.html && grep -q 'test.md' files.html && grep -q 'SKILL.md' files.html && grep -q '#0f172a' files.html && grep -q 'href="index.html"' files.html && ! grep -q 'the-framework' files.html
Uncertainty: 0

Create `files.html`: a page titled "Files" with a `<ul>` listing the repo's markdown
files, one `<li>` each, with the path in `<code>` and one line saying what it holds:

- `README.md` — what the site is, how to run it locally, and how it deploys to GitHub Pages.
- `test.md` — a one-line note: the favourite colour, blue.
- `.agents/skills/<name>/SKILL.md` — one entry for all of them together: the
  instructions for the coding-agent skills used on this repo (orchestration,
  tickets, queue, and others). Count them with `git ls-files '.agents/skills/*/SKILL.md' | wc -l`
  and give the count.

Leave out everything under `.the-framework/`: those are internal run logs the
deploy deliberately keeps off the public site. Under the list, add a relative link
back to the home page: `<a href="index.html">Home</a>`. Style links readable on the
dark background (e.g. colour `#93c5fd`).

## Add a nav to index.html linking to both pages

Level: simple
Files: index.html
Needs: Write the About page (about.html), Write the Files page (files.html)
Check: grep -q '<nav' index.html && grep -q 'href="about.html"' index.html && grep -q 'href="files.html"' index.html && grep -q 'Hello, and welcome.' index.html
Uncertainty: 0

In `index.html`, add a `<nav>` under the existing `<h1>` with two relative links,
`<a href="about.html">About</a>` and `<a href="files.html">Files</a>`. The body is a
centred flex container today, so add `flex-direction: column` to keep the nav
below the heading rather than beside it. Style the links readable on the dark
background (colour `#93c5fd`, a gap between them). Keep the heading text, the
favicon links and their comment exactly as they are.

## Ship the new pages and list them in the README

Files: .github/workflows/deploy.yml, README.md
Uncertainty: 1

Kept by the orchestrator, not a subagent: it changes what the deploy publishes,
which is the person's call. Add `about.html files.html` to the `cp` line of the
`Stage site` step in `deploy.yml` — without it the nav links 404 on the live site —
and add both pages to the Files table in `README.md`.
