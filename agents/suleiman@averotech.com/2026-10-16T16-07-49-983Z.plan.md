# Add an About page, a Files page, and a nav to the static site

The project is a tiny static site at the repository root: `index.html` is the whole
site, with inline styles, `favicon.ico` and `favicon.svg`. There is no build step, no
dependencies, no tests. Do not add any. Do not touch files outside your task's `Files:`
line; in particular leave `README.md`, `test.md`, `.the-framework/`, `.agents/`,
`.claude/` and `.openagent/` alone.

Every new page must match the style of `index.html`. Copy its `<head>` exactly
(charset, viewport, the comment about relative favicon links, both `<link rel="icon">`
tags with relative hrefs `favicon.ico` and `favicon.svg`), changing only `<title>`.
Keep its CSS as-is (dark `#0f172a` background, the same font stack, body centered
with flex, `h1` in `#f8fafc` at 3rem weight 600), and add only what a page with more
than a heading needs:
- `flex-direction: column;` on `html, body` so items stack.
- body text (`p`, `li`) in `#cbd5e1`, `font-size: 1.125rem`, `line-height: 1.6`,
  `max-width: 40rem`, and `padding: 0 1.5rem` on the content so it doesn't touch the edges.
- links (`a`) in `#f8fafc` with an underline.
All links are relative (`index.html`, `about.html`, `files.html`), never root-absolute:
the site is served from the `/test-project/` subpath. Use two-space indentation in CSS,
as `index.html` does.

Check: test -f about.html && test -f files.html && grep -q 'href="about.html"' index.html && grep -q 'href="files.html"' index.html && grep -q 'href="index.html"' about.html && grep -q 'href="index.html"' files.html && grep -q 'cp index.html about.html files.html favicon.ico favicon.svg _site/' .github/workflows/deploy.yml

## Write about.html from the README

Level: simple
Files: about.html
Check: grep -q '<title>About</title>' about.html && grep -q '<h1>About</h1>' about.html && grep -q 'No build step, no dependencies.' about.html && grep -q 'href="favicon.svg"' about.html && grep -q 'href="index.html"' about.html
Uncertainty: 0

Create `about.html` at the repository root. `<title>About</title>`, then in the body an
`<h1>About</h1>`, one short `<p>` saying what this repo is, and a last `<p>` with a link
`<a href="index.html">Back to home</a>`.

Take the paragraph from the first paragraph of `README.md`, lightly reworded to read as
an about page but keeping the sentence "No build step, no dependencies." verbatim. It
should say: this is a single static page; no build step, no dependencies; it shows one
centered greeting, "Hello, and welcome.", on a dark background; it is deployed with
GitHub Pages. Two to four sentences, no more.

## Write files.html listing the markdown files

Level: simple
Files: files.html
Check: grep -q '<title>Files</title>' files.html && grep -q '<h1>Files</h1>' files.html && grep -q 'README.md' files.html && grep -q 'test.md' files.html && grep -q 'href="favicon.svg"' files.html && grep -q 'href="index.html"' files.html
Uncertainty: 0

Create `files.html` at the repository root. `<title>Files</title>`, then in the body an
`<h1>Files</h1>`, a `<ul>` with one `<li>` per markdown file, and a last `<p>` with a link
`<a href="index.html">Back to home</a>`.

List exactly the two markdown files at the repository root, and nothing under hidden
directories (those are agent tooling and internal notes, deliberately kept off the public
site). Each `<li>` is one line: the file name in `<code>`, a dash, and what it holds:
- `<code>README.md</code>` — what the site is, how to run it locally, and how it is deployed to GitHub Pages.
- `<code>test.md</code>` — a one-line note recording a favorite color (blue).

Style `code` to match: `color: #f8fafc;` and the font stack
`ui-monospace, SFMono-Regular, Menlo, monospace`. Use a list with no bullets
(`list-style: none; padding: 0;` on `ul`).

## Add a nav to index.html

Level: simple
Files: index.html
Needs: Write about.html from the README, Write files.html listing the markdown files
Check: grep -q '<nav>' index.html && grep -q 'href="about.html"' index.html && grep -q 'href="files.html"' index.html && grep -q '<h1>Hello, and welcome.</h1>' index.html
Uncertainty: 0

In `index.html`, add a `<nav>` directly below the existing `<h1>`, with two links:
`<a href="about.html">About</a>` and `<a href="files.html">Files</a>`. Leave the `<h1>`,
the `<head>` and the `<title>` unchanged. Add to the existing `<style>` only what the nav
needs: `flex-direction: column;` on `html, body` so the nav sits under the heading;
`nav { display: flex; gap: 1.5rem; }`; and `nav a` in `#cbd5e1`, `font-size: 1.125rem`,
underlined. Both linked files already exist on your branch.

Kept by the orchestrator, not a subagent: it goes beyond the three things asked, so the

`cp` line to `cp index.html about.html files.html favicon.ico favicon.svg _site/`.
