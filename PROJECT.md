# Project Description

**Hello** is a minimal static website: a single HTML page that shows one centered
greeting, "Hello, and welcome.", on a dark background.

## Purpose

The project exists as a small, self-contained test site. It has no build step,
no dependencies, and no JavaScript framework, which makes it a simple target for
trying out tooling, workflows, and deployment pipelines.

## What's inside

- `index.html` – the page itself, with markup and inline styles
- `favicon.svg` and `favicon.ico` – the site icon for modern and legacy browsers
- `.github/workflows/deploy.yml` – GitHub Actions workflow that publishes the site

## Deployment

The site is published to GitHub Pages on every push to `main` and is live at
https://suleimansh.github.io/test-project/.

See `README.md` for setup and local run instructions.
