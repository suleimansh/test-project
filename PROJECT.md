# Project description

**Hello** is a minimal static web page published with GitHub Pages at
https://suleimansh.github.io/test-project/.

It shows a single centered greeting — "Hello, and welcome." — on a dark
background. There is no build step and no dependencies: the whole site is
`index.html` with inline styles, plus an SVG favicon and an ICO fallback.

Every push to `main` deploys the site through `.github/workflows/deploy.yml`.
See [README.md](README.md) for how to run it locally and how deployment works.
